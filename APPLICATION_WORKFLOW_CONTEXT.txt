1. EXECUTIVE OVERVIEW & PLATFORM PURPOSE
--------------------------------------------------------------------------------
Digital Heroes is an industrial-grade, commercial Web-to-Print (W2P) manufacturing
platform engineered strictly to the Level 2 PRD specification.

It completely eliminates static e-commerce "SKU bloat" by implementing a dynamic,
parameter-driven manufacturing workflow:
- Millimetre-accurate surface area and volume pricing
- In-browser interactive vector canvas design studio with live factory margin guides
- Automated prepress preflight validation (DPI >= 300, CMYK/FOGRA39, bleed margins)
- Cryptographic 2-way proof approval gate with SHA-256 digital signature hashes
- Factory RIP prepress print engine (300 DPI vector PDF + 300 DPI master PNG with embedded
  ISO 15076-1 / FOGRA39 binary ICC profile and cut contour)
- Variable Data Print (VDP) engine merging up to 5,000 CSV records (runners/barcodes)
- Real-time factory shop-floor kanban pipeline for order fulfillment
- Transactional email engine with an idempotency deduplication gate
- Ready-to-connect UK Courier Shipping Adapter (Royal Mail Click & Drop v1 & DPD UK)
  with automated 4x6" PDF thermal shipping label generation and tracking webhooks
- Ready-to-connect Xero Cloud Accounting Sync Adapter (OAuth2, ACCREC invoice payload,
  Chart of Accounts Code 200, 20% UK VAT OUTPUT2, and PDF invoice attachment)
- PostgreSQL database on Supabase with 18 relational tables and 29 RLS policies

3. THE COMPLETE 6-STAGE MANUFACTURING LIFECYCLE
--------------------------------------------------------------------------------

[STAGE 1: DYNAMIC CONFIGURATION & MILLIMETRE PRICING]
- URL: /products/[slug] (e.g. /products/vinyl-stickers)
- Surface Area Calculation:
    Area (cm²) = (Width mm × Height mm) / 100
- Multipliers:
    Subtotal Net = Base Area Rate × Material Multiplier × Finish Multiplier × Cut Multiplier
- Volume Discount Curves:
    * 1 – 49 units:       0% base rate
    * 50 – 99 units:      5% discount
    * 100 – 249 units:   10% discount
    * 250 – 499 units:   18% discount
    * 500 – 999 units:   25% discount
    * 1,000 – 2,499 units: 32% discount
    * 2,500 – 4,999 units: 40% discount
    * 5,000+ units:      50% discount
- Setup Fees & Minimum Order Floor: Setup fees amortized over quantity; orders below
  minimum order value (£15 – £35 depending on division) are automatically rounded up.
- Tax Math: UK VAT (20.0%) calculated server-side in integer cents to eliminate
  floating-point rounding errors.
- Action Buttons (Equalized 3-Pillar Cockpit):
    * [Proceed to Designer]: Opens vector canvas with pre-configured dimensions.
    * [Add to Cart 🛒]: Saves item to local storage and updates cart badge.
    * [Quick Checkout]: Fast-paths directly to checkout summary.


[STAGE 2: IN-BROWSER VECTOR DESIGNER STUDIO & PREFLIGHT]
- URL: /designer?product=...&w=...&h=...&qty=...
- Vector Studio Capabilities:
    * Multi-layer text engine with Google Fonts (Inter, Roboto, Playfair, Space Mono).
    * Dynamic font sizing, tracking, alignment, and hex/swatch color pickers.
    * Vector shapes: Rectangles, circles, badge frames, cut paths.
    * Artwork upload support: PDF, SVG, AI, PNG, and JPEG.
- Live Factory Margin Guides:
    * Safe Margin Guide: Inner dashed green line (-3mm inside trim).
    * Cut Line: Solid border representing finished finished trim dimensions.
    * Bleed Line: Outer dashed red line (+3mm) for full-bleed printing.
- Automated Preflight Engine (lib/designer/preflight.ts):
    * DPI Resolution Check: Flags uploaded bitmap artwork below 300 DPI.
    * Color Space Inspection: Inspects RGB vs CMYK profiles and recommends FOGRA39 conversion.
    * Bleed Margin Validation: Warns when background artwork does not extend to the +3mm bleed edge.
- Cloud Persistence (/api/designs/save):
    * Serializes vector canvas JSON state into Supabase `public.designs` table.
    * Allows reloading design state via /designer?designId=... for re-editing or 1-click reorders.


[STAGE 3: MULTI-PRODUCT CART & AUTHORITATIVE CHECKOUT]
- URL: /cart and /checkout
- Shopping Cart:
    * Supports multiple configured items across different manufacturing divisions.
    * Live recalculation of volume discounts upon quantity changes.
- Price Anti-Tampering:
    * Client-side submitted prices, subtotals, and VAT are strictly ignored by the server.
    * Server recalculates exact net subtotals, discounts, and 20% UK VAT authoritatively.
- Payment Processing (/api/checkout/webhook):
    * Stripe simulated payment integration (checkout.session.completed).
    * Automatically generates official Order # (ORD-YYYY-NNNN) and marks order as PAID.


[STAGE 4: CRYPTOGRAPHIC PROOF APPROVAL GATE (ZERO TRUST)]
- URL: /customer/dashboard (Proof Review Tab) and /admin/production
- Proof Revisioning:
    * Tracks revisions across v1, v2, v3 with change request logs.
- Cryptographic Sign-Off:
    * Upon customer approval, computes SHA-256 digital signature hash:
      SHA-256(Customer ID + Order # + Proof Version + Timestamp + Client IP)
- Authoritative Production File Lock:
    * Production endpoints return HTTP 423 Locked until proof is customer-approved.
    * Factory RIP prepress print engine strictly refuses to generate or release print
      files without a validated digital signature certificate.


[STAGE 5: FACTORY SHOP-FLOOR OPERATIONS & PREPRESS RIP ENGINE]
- URL: /admin/production
- Floor Operations Kanban Pipeline:
    * Stages: QUOTE → ORDER → ARTWORK → PROOF → PRODUCTION → COMPLETED.
    * Machine Line Allocation: Schedules jobs to specific equipment:
      - Roland TrueVIS VG3-640 (ECO-UV Inkjet & Cutter)
      - Mimaki UJF-3042 MkII UV Flatbed
      - Trodat Multi-Laser Engraver System
      - Trotec Speedy 400 CO2 Laser System
- Prepress Master Outputs (lib/print-engine/generator.ts):
    1. Vector Print PDF Master:
       - 300 DPI vector output with 3mm bleed margin.
       - 10mm technical slug containing order barcode, specs, and operator notes.
       - Spot magenta (#FF00FF) cut contour line.
       - Embedded ISO 15076-1 / FOGRA39 CMYK /ICCBased ColorSpace object (Object 7)
         and /OutputIntent dictionary (Object 8).
    2. High-Resolution 300 DPI Master PNG:
       - 300 DPI resolution via RFC 2083 pHYs chunk (11,811 pixels/meter).
       - Embedded RFC 2083 iCCP chunk (488-byte ISO 15076-1 / FOGRA39 binary profile).
       - Prepress cut contour, crop marks, and CMYK process swatches.
    3. Standalone Hardware ICC Export:
       - Direct endpoint at /api/production/icc/FOGRA39 serving ISOcoated_v2_eci_FOGRA39.icc
         for Roland VersaWorks and Mimaki RasterLink hardware RIPs.
- Variable Data Print (VDP) Engine (lib/print-engine/variable-data.ts):
    * Merges up to 5,000 CSV records into production runs (runner names, bib numbers).
    * Dynamic Code 128 and QR code rendering for timing chips.
    * Auto-shrink typography with minimum point-size floors.


[STAGE 6: DISPATCH LOGISTICS & ACCOUNTING SYNCHRONIZATION]
- Dispatch Logistics Modal (/admin/production):
    * Integrated with Courier Shipping Adapter (lib/shipping/carrier-adapter.ts).
    * Royal Mail Click & Drop API v1:
      - Generates official RM48-XXXXXXXXXGB tracking numbers and royalmail.com portal links.
      - Produces standard 4x6" (%PDF-1.4) thermal shipping labels with vector barcodes.
    * DPD UK Shipping API:
      - Generates DPD 12-digit consignment numbers (0542XXXXXXXX) and tracking links.
      - Produces standard DPD 4x6" (%PDF-1.4) thermal shipping labels.
    * Tracking Webhook Listener (/api/shipping/webhook):
      - Ingests Royal Mail & DPD transit/delivery webhooks and advances order to DISPATCHED or DELIVERED.
    * Deterministic Fallback: When no external carrier keys are in .env.local, operates
      in simulated fallback mode without breaking or throwing 500 errors.
- Accounting & Tax Invoicing (lib/accounting/xero-client.ts):
    * Authoritative Commercial Tax Invoice Generator (lib/orders/invoice-pdf.ts):
      - Renders %PDF-1.4 commercial tax invoice with HMRC VAT # GB 941 2026 88 and 20% VAT.
    * Xero Accounting Sync Adapter:
      - OAuth2 token exchange with identity.xero.com.
      - Builds standard Xero ACCREC payload with Sales Revenue Account Code 200 and Tax OUTPUT2.
      - Uploads generated PDF invoice via Xero Attachments API.
      - Sync endpoint available at /api/invoices/[orderId]/xero-sync.
