1. EXECUTIVE OVERVIEW
--------------------------------------------------------------------------------
Digital Heroes is an industrial-grade, commercial Web-to-Print (W2P) manufacturing
platform engineered strictly to the PRD Level 2 specification.

All requirements from the original PRD have been systematically inspected, audited,
implemented, and verified in the live code repository:
- 100% of functional frontend pages, backend APIs, and database migrations are operational.
- Real Supabase Auth, session cookie synchronization, and route protection middleware.
- Dedicated separate login portals for Customers (/login) and Administrators (/admin/login).
- Full customer self-service: registration, forgot/reset password, profile management,
  order history, order search & filtering, full order details drawer, active proofs (v1/v2/v3),
  change requests, saved designs (with Edit in Canvas & Delete), and itemized VAT invoices.
- Multi-product shopping cart (/cart) with quantity editing, item removal, volume discount
  recalculation, and checkout routing.
- Real-time in-browser vector canvas designer (/designer) with safe margins (-3mm), bleed
  boundaries (+3mm), text editing, typography, color palettes, image uploads, cloud saving,
  and state reloading from saved designs.
- Prepress validation and preflight engine for DPI (>=300), color space, and bleed margins.
- Authoritative server-side pricing engine with integer-cent safety and minimum order protection.
- Cryptographic Proof Approval Gate locking production files (HTTP 423) until customer approval.
- High-resolution RIP PDF print generator with FOGRA39 CMYK simulation and crop marks.
- Variable Data Print (VDP) engine merging up to 5,000 CSV records with Code 128 / QR barcodes.
- Factory shop-floor operations kanban pipeline with machine line scheduling.
- Back-office administration for customer directories, products & substrates, millimeter
  pricing curves, volume discounts, order refunds, and outbox email delivery logs.
